# Практика 1. Простые игровые объекты

Все задания запускаются на компьютере. Размер игрового поля:

```python
WIDTH = 160
HEIGHT = 120
```

Используй основу:

```python
from api import GameObject, RED, SKY
from backends.tkinter_backend import run


class MyGame:
    def __init__(self):
        pass

    def update(self, keys):
        pass

    def draw(self, gfx):
        gfx.clear(SKY)
        gfx.present()


run(MyGame())
```

## Задание 1. Красный квадрат

Нарисуй красный квадрат:

- координаты: `x = 30`, `y = 40`;
- размер: `20x20`.

Подсказка: создай `GameObject` в `__init__`, а нарисуй его в `draw`.

## Задание 2. Три объекта

Нарисуй:

- красный квадрат слева;
- зеленый квадрат в центре;
- синий прямоугольник справа.

Объекты не должны пересекаться.

## Задание 3. Автоматическое движение

Сделай квадрат, который сам движется вправо.

1. Задай ему `vx = 2`.
2. Каждый кадр вызывай `move()`.
3. Когда квадрат уйдет за правый край, перенеси его к левому краю.

## Задание 4. Управление игроком

Сделай объект, которым можно управлять:

- `keys.left` — движение влево;
- `keys.right` — движение вправо;
- `keys.up` — движение вверх;
- `keys.down` — движение вниз.

Если направление не нажато, соответствующая скорость должна быть равна нулю.

## Задание 5. Границы экрана

Возьми решение предыдущего задания.

Не разрешай игроку выходить за игровое поле. Используй:

```python
player.keep_inside(WIDTH, HEIGHT)
```

## Задание 6. Отскок от стен

Создай квадрат, который движется по диагонали:

```python
vx = 2
vy = 1
```

Когда он касается левой или правой стены, меняй знак `vx`.
Когда касается верхней или нижней стены, меняй знак `vy`.

## Задание 7. Столкновение

Создай игрока и подарок.

- игрок управляется стрелками;
- подарок стоит неподвижно;
- если игрок касается подарка, подарок становится зеленым;
- если не касается — подарок красный.

Для проверки используй:

```python
player.overlaps(gift)
```

## Задание 8. Поймай подарок

Подарок падает сверху вниз.

- игрок двигается влево и вправо;
- если игрок поймал подарок, счет увеличивается;
- после поимки подарок снова появляется сверху;
- если подарок упал ниже экрана, он также возвращается наверх.

Выведи счет:

```python
gfx.text(2, 2, "SCORE " + str(score), WHITE)
```

## Задание 9. Две цели

Добавь в игру два падающих объекта:

- красный подарок дает `1` очко;
- зеленый подарок дает `2` очка;
- они падают с разной скоростью.

## Задание 10. Мини-игра

Сделай законченную игру:

- игрок двигается в четырех направлениях;
- красная цель дает очко;
- синяя опасность отнимает очко;
- после столкновения объект появляется в другом месте;
- счет не может быть меньше нуля.

Дополнительное задание: меняй цвет фона, когда игрок касается опасности.
